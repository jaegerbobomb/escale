# Show a ticket

1. Click **Ticket** in the header bar (the ticket icon on a narrow window) for the next
   booking of your trip, from any tab; or **Ticket** on any booking's card in **Current**.
2. The ticket opens full screen: the code to scan, the ticket number below it, and
   what the ticket is for. The screen brightness goes up where the device allows it.
3. **Back** (the arrow) returns to the trip.

The code is drawn from the copy of the ticket kept on this device: no network is
needed, in a tunnel or abroad.

If the booking has no code, or a Data Matrix code that Escale cannot draw yet, the view
offers **Open the original document** instead: the PDF or file you imported.

Hotels and restaurants have no **Ticket**: what you imported for them is a booking, not
something to scan. Open the booking and use **Booking document** to see the file.
