# Fonts

`AdwaitaSans-Regular.ttf` and `AdwaitaSans-Bold.ttf`: Adwaita Sans 49.0, latin subset,
under the SIL Open Font License 1.1 (`AdwaitaSans-LICENSE.txt`). Converted from the WOFF
files of the `@fontsource/adwaita-sans@5.3.0` npm package with fontTools (no glyph
change). Characters outside the latin subset fall back to the platform font.
